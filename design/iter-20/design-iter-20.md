## 1. 范围与不做

- **做**：≤768px 侧栏抽屉态全规格（入口钮/顶条、开/合/遮罩、宽 264px 平移、关闭三径、瞬态不持久化、rail 隐藏口径）；≤480px 正文与 Composer 收窄态（padding 12px、气泡 ≤92%、发送钮 44、hint 触控口径、placeholder 触控口径）；≤480px 设置弹窗全屏态（inset 0、单滚动、导航横向滚动条、二级弹窗同口径）；触屏常显态（「···」/消息操作栏 `hover: none` 常显）与 44px 命中区口径（发送钮视觉放大定夺 + icon 钮热区扩大）；44px 热区标注图；走查四象限清单 31 条（REQ-049 7 / REQ-050 6 / REQ-051 5 全映射 + 桌面零回退 A 组）；样件文案 M44~M45 逐字登记；spec「涉及页面」回填拟文。
- **不做**（登记防膨胀）：**管理后台移动端**（CHG-014 定夺⑤维持桌面优先——本稿零涉及，现状 overflow-x 兜底）；**移动端原生能力面**（PWA/推送/软键盘 100dvh 等——暂缓池条目）；**断点令牌**（定夺②就地媒体查询）；**半屏/底部 sheet 弹窗形态**（定夺④定案全屏化，sheet 留池不复议）；**抽屉内独立关闭钮**（遮罩/Esc/选中会话三径已覆盖，入口钮 aria-expanded 承载状态语义——不新增部件）；**移动端手势**（左滑回抽屉/右滑关——首版零手势，点击口径可断言）；**触屏切换 toast**（无服务端动作，零反馈件）；**design/proto 与 design/iter-1~19 不同步**（移动断点对既有桌面稿不可见 = 桌面形态零变化的机制化表达，CHG-014 设计资产承载段原文）；**发送钮 hover:hover 桌面 36px 零变化**（仅 ≤480px 视觉 44，定夺⑥推荐）。

## 2. ≤768px 侧栏抽屉态（REQ-049 描述前段落形）

### 2.1 断点与骨架切换（定夺②既定，就地媒体查询）

```
@media (max-width: 768px)            ← 断点值（不设令牌，沿登录页就地媒体查询先例 LoginView L467 体例）
  .layout 双列 flex → 单列：侧栏脱离文档流（position:fixed overlay），rail 不渲染
  主区新增移动顶条（48px，见 §2.2）
>768px：现行骨架逐像素零变化（零回退硬约束——媒体查询全带 max-width 上界，无 min-width 面）
```

### 2.2 移动顶条与入口钮（定夺①推荐）

| 项 | 口径（随基线定案） |
|---|---|
| 载体 | ≤768px 主区顶部新增**移动顶条**：高 48px、底 `--c-surface`、下描边 `--c-border`；左端入口钮 + 当前会话名（`--c-text-1` 13px/500，超长 ellipsis 截断）；>768px 整条不渲染（`display:none` 缺省，媒体查询内恢复） |
| 入口钮 | 44×44 图标钮（汉堡「☰」三横线 SVG，`--c-text-2` 线色），`--r-sm`，hover 底 `--c-hover-bg`（视觉反馈级保留），`aria-expanded` 随抽屉开合，`aria-label` = **M44「打开会话列表」**；命中区 = 44×44 视觉即热区（REQ-049 描述「触发钮 ≥44px」兑现） |
| 会话名 | 当前会话 title 同源（新建未命名会话沿现状命名规则，零新文案）；抽屉选中切换后同步 |
| 理由 | 顶条同时承载入口钮位置稳定性（fixed 悬浮钮会遮挡消息流首行）与移动端上下文（当前会话名——桌面侧栏选中态在抽屉化后不可见，顶条补位）；48px = 间距令牌 32+16 组合内的控件行高节奏，零新几何值 |

### 2.3 抽屉开/合态全规格

| 态 | 规格 |
|---|---|
| **关闭（默认）** | 侧栏不渲染视觉面（`transform:translateX(-100%)` + `visibility:hidden` 或 v-if——实现级决策）；rail 56px **不渲染**（≤768px 零 rail 口径：56px 在 480px 视口仍占 11.7% 且无会话名，CHG-014 定夺③取证）；正文列宽 = 视口 100%（验收 1 断言）；遮罩不渲染 |
| **展开** | 入口钮点按 → 侧栏 `position:fixed; left:0; top:0; bottom:0`，宽 **264px**（既有侧栏原样平移——内容形态与桌面侧栏零差异：品牌区/新建/搜索/会话列表/账户区全保留；<330px 视口取 `min(80vw, 264px)`），`z-index` 高于正文与顶条；遮罩全屏 `var(--c-mask)`（浅 rgba(31,35,41,.4) / 暗 rgba(0,0,0,.55)——既有令牌零新值），`z-index` 低于侧栏 |
| **动画** | 侧栏 translateX(-100% ↔ 0) + 遮罩 opacity 0 ↔ 1，均 **.15s ease**（tokens 动效令牌唯一值，零新动效值）；`prefers-reduced-motion` 沿全局既有口径（如有）零新增 |
| **关闭三径** | ① 点遮罩任意处 ② Esc ③ 选中会话（自动关 + 正文全宽恢复，REQ-049 主流程）；三径同一关闭函数，零分叉 |
| **瞬态不持久化** | 开合态 = 组件本地 ref，**不写 localStorage 任何键**（`mm-sidebar-collapsed` 仅承载桌面 rail 收起态，≤768px 断点下该键零读写——REQ-049 验收 6 断言）；刷新/重进默认关 |
| **生成中开合** | 抽屉为纯容器切换（fixed overlay），与 SSE 流零事件交互（CHG-014 内容 3.4 取证）——生成中开合抽屉流帧序不变（验收 7 vitest 断言）；抽屉内会话切换沿 REQ-004 既有口径零变化 |
| **焦点** | 入口钮 `:focus-visible` 焦点环 `--c-focus-ring` 沿用；抽屉展开后焦点移入侧栏首个可聚焦件、关闭后还收入口钮（键盘可达，`aria-expanded` 承载状态）——实现级细则，登记 T2 spike |

## 5. 触屏常显态与 44px 命中区（REQ-051 落形）

### 5.1 两处功能入口常显（`@media (hover: none)`，零 JS 嗅探）

| 处 | 桌面基线（零变化） | 触屏态（常显） |
|---|---|---|
| 会话列表项「···」 | `.item:hover` 浮现（SessionListItem L175，design-iter-11 §1.2 走查 5） | `hover:none` 下 opacity 常为 1（无 hover 即可见，验收 1）；28px 视觉尺寸不变 |
| 消息操作栏（复制/修改） | `.msg-col:hover .action-btn` opacity 0→1（MessageBubble L341） | `hover:none` 下 opacity 常为 1；版本箭头本就常显零变化；icon 24px 视觉尺寸不变 |

- **同一 CSS 面双态零 JS 分叉**（CHG-014 定夺⑥）：`@media (hover:none){ .dd-trigger,.action-btn{opacity:1} }` 一处规则；`hover:hover` 端规则零触碰。
- **视觉反馈级 hover 保留**（active 态兜底）：列表行 hover 底、按钮 hover 底在 `hover:none` 下由 active 按压态（`scale .98`/底色变化）自然承载——不消除任何既有规则。

### 5.2 44px 命中区口径（定夺⑥推荐：分类处置）

| 对象 | 口径 | 理由 |
|---|---|---|
| 发送/停止钮 | **≤480px 视觉放大至 44×44**（§3）；481~768px 维持 36×36 + 透明 padding 热区扩至 44 | 主操作钮视觉即热区最简可断言；≤480px 是握持拇指主区值得放大；桌面（>768px hover:hover 面）36px 逐像素零变化（REQ-051 验收 3） |

## 10. 令牌 / 组件 / 卫生评估结论（零新增令牌自查）

- **零新增令牌、零自造色值（逐项自查）**：遮罩 = `--c-mask` 既有（CHG-014 定夺⑦明文复用）；顶条/抽屉 = surface/border/text-1/text-2/hover-bg 既有；44px 热区 = 几何标注非令牌；断点 768/480 = 就地媒体查询不设令牌（定夺②）；动画 .15s ease = tokens 动效唯一值；导航横切 = 既有分区钮样式平移。**无 design-system 令牌变更提案**。
