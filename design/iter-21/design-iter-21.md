## 1. 范围与不做

- **做**：第七分区「用量与费用」全规格（导航项插入位/今日摘要行/时间窗切换/每日列表体例/模式分布注记）；四分支态全形（正常数据/空态/单价未配置/加载与错误）；API 形状定案（`GET /api/usage/summary`，§5）；样件文案 U1~U16 逐字登记；走查清单 28 条（A 组新增 17 + B 组六分区零回退 8 + C 组全局 3）；spec「涉及页面」指针回填拟文；design/proto 用量分区示意同步。
- **不做**（登记防膨胀）：**图表**（柱状/折线——REQ-025 先例「图表不做」，列表承载）；**费用分项展开**（input/output/cache_hit 三分项成本——个人面只呈合计，分项留 admin 侧；admin 卡 A 体例的 `bd-grid` 不引入）；**导出/CSV**；**按会话粒度明细**（遥测无会话维度的成本归属承诺，session_id 仅压缩行有值）；**30 天以上窗口**（上限 90 保留期内取 30 封顶，CHG-015 定夺②）；**刷新按钮**（数据随分区打开/窗口切换拉取，回合结束后重新打开弹窗自然刷新——不常驻轮询）；**KeyModeCard 今日文案并入**（定夺④零改动）。

## 5. API 形状定案（T2 实现以此为准）

`GET /api/usage/summary?days=N`（本人 user_id 从 HttpOnly Cookie 会话凭证解析；`days ∈ {7, 30}`，缺省 7，越界 422——枚举校验非区间，与 admin `ge=1 le=90` 不同为有意口径：个人面档位固定）

```json
{
  "window": { "days": 7, "date_from": "2026-08-16", "date_to": "2026-08-22" },
  "price": { "configured": true, "input_per_mtok": 2.0, "output_per_mtok": 8.0, "cache_hit_per_mtok": 0.2 },
  "today": { "mode": "unified", "daily_limit": 30, "used_today": 5, "cost_total": 0.012345 },
  "daily": [
    { "day": "2026-08-22", "turns": 5, "tokens_prompt": 12345, "tokens_completion": 6789,
      "cache_hit_tokens": 4200, "cost_total": 0.012345 }
  ]
}
```

- 聚合：telemetry 按 `user_id × day`（`day` 倒序）；`turns` = 当日 `COUNT(DISTINCT turn_id)` 且 `turn_id IS NOT NULL`（endpoint=turn/research 的 llm 行承载回合计数；手动压缩 turn_id 为 NULL 不计回合——与 REQ-024 回合计口径一致）；`tokens_prompt/completion` = 当日 llm 行 + compress 行 tokens_prompt 合计（admin `_cost6` 输入口径同源：compress 行 tokens_prompt 按输入计价）；`cache_hit_tokens` = 当日 llm 行求和，全缺失 → null。
- 成本：`_cost6` 同构提取（admin.py L392-401 → 公共函数，实现级决策 T2 登记）；仅 mode='unified' 的 llm 行 + compress 行计入；`round(..., 6)` 后端存值、前端 `toFixed(4)` 呈现（admin 同分工）。
- 与 usage_daily 口径差异注记（风险②处置）：usage_daily.`turns` 为回合落账口径（含被熔断拒绝后的补偿语义差异不存在——两源在正常路径数字一致；若 QA 抽样发现差异，以 telemetry 聚合为个人面唯一数据源、差异原因留档 verify，不改回 usage_daily）。
- 错误面：未登录 401；days 越界 422；跨用户 = 无此面（user_id 仅从凭证解析，query/body 不接受 user_id 参数——泄露面结构性消除）；无数据 = `daily: []` 空数组非 404。
