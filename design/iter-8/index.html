② 迁移提示条触发规则与「暂不导入」再提示节奏（spec 定案「下次登录再次提示」） 登录后检测 + 主界面顶部 + 两条独立堆叠：每次登录成功后前端检测本地旧数据（会话 = IndexedDB 旧库；档案 = 旧 localStorage 字段），检测到即在主界面顶部显示对应提示条， 会话条与档案条各自独立动作；无旧数据零打扰。「暂不导入」= 该条本次登录内不再显示（含刷新）、零上传；下次登录重新检测、仍有则再提示；不提供「永久忽略」。 同登录内反悔无重入口（重新登录即再看，已知取舍登记在案）。导入完成：会话本地转只读备份 30 天后清除；档案本地立即清除。 spec「下次登录再次提示」的直接落法；登录时点检测一次、节奏可预期；密钥凭据上传与普通数据迁移分开确认（安全语义），故不合并为一条； spec REQ-018 写「登录后以提示条引导」——主界面顶部即字面落法，且档案数据无 30 天清除兜底、放设置页有永不被发现的风险。
备选（未采纳）：档案条留设置页 + 会话条内交叉链接（多一跳且主界面仍需一条）；每次页面加载都提示（打扰过重）。
③ 管理后台入口可见性口径（仅管理员可见的实现形态） 侧栏底栏盾牌入口 + 独立路由 + 服务端 403 双保险：主界面侧栏底栏新增盾牌 icon-only ghost（26px，title/aria-label「管理后台」，置于状态点与登出之间）， 仅登录用户带管理员标记时渲染；后台为独立路由 /admin（顶栏 + tab 页面骨架，非主界面内嵌）；「返回主界面」回主路由。 安全边界在服务端：admin 接口对非管理员一律 403；未登录访问 /admin 跳登录（redirect 回跳）。 与 iter-6 4.2 侧栏底栏增量同位（用户名/登出所在 = 账号级操作聚集地）；设置页语义不符（后台非用户偏好）；纯 URL 直达可发现性差； 前端隐藏 + 后端 403 双保险恰好覆盖 T2 验收「普通用户访问后台路由/接口返回 403、不暴露任何后台数据」。
备选（未采纳）：设置页内入口；顶栏入口（顶栏为会话级操作区）；仅 URL 直达。
④ 用量列表的列与筛选排序最小集 4 列 + 2 筛选 + 3 排序：列 = 日期 / 用户名 / 请求数 / token 数（用户 × 自然日聚合行，token 为每请求合计）； 筛选 = 用户下拉（含「全部用户」，默认全部）+ 日期起止（默认最近 7 天）；排序 = 日期/请求数/token 数列头点击切换升降序（默认日期降序）。 不做：分页、图表、导出、token 拆输入/输出。数据缺失以表内琥珀行标注缺失时段（不估算补齐）。 4 列恰是 REQ-025 验收「按用户按日的请求数与 token 数与后端调用日志计数一致（抽样比对 3 天）」的最小比对字段集； 默认 7 天窗口防「用户数 × 天数」行数膨胀（替代分页）；缺失标注对应 spec 异常分支「显示已有数据并标注缺失时段，不编造」。
备选（未采纳）：分页（最小口径外增量）；token 拆输入/输出（T1 记录口径为合计）。
