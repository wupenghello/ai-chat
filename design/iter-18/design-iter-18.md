| 项 | 口径（随基线定案） |

| 旁置标签 | M38「深度研究」13px/500，紧随开关右侧 8px：关闭 = `--c-text-2` / 开启 = `--c-primary`（变色即模式反馈）/ 禁用 = `--c-text-3` |
| aria | 开关 `aria-label` = M39「深度研究模式开关」；开关状态即模式状态（无需额外 live region——hint 文案同步切换承载语义） |

| 位置理由 | ① 角落放置不侵占输入空间（composer 紧凑基调不变）；② 模式为**回合级属性**，开关在输入区 = 与发送动作同区表达，发送后复位语义自然（REQ-047 定夺⑦推荐理由的形态兑现）；③ ToggleSwitch 复用 = 零新增组件形态（分段控件备选的会话级语义误导见定夺①备选栏） |

### 2.2 四态规格总表（只画理想路径不合格——态逐个定死）

| 态 | 触发 | 用户所见（= 验收口径） |
|---|---|---|
| **关闭态（默认）** | 挂载初始态（每次挂载默认关，不持久化） | 开关关（`--c-hover-bg` 轨道）+ 标签 M38 `--c-text-2` + hint 右 = 存量「Enter 发送 · Shift+Enter 换行」逐字零回退；placeholder / 边框 / 发送钮零变化 |
| **开启态** | 点击开关 | 开关开（`--c-primary-solid` 轨道、滑块右移 16px）+ 标签 M38 转 `--c-primary` + **hint 右替换为模式提示 M40 逐字**（「已开启深度研究：…耗时较长」——高成本模式的预期管理常驻自释）；输入行零变化（不加边框强调——与 focus-within 主色描边语义冲突，定夺②） |
| **禁用态** | `research_available !== true`（GET /api/quota 加法字段，§6） | 开关 `disabled`（opacity .45、cursor not-allowed、点击无反应）+ 标签 M38 `--c-text-3` + **hint 右替换为禁用提示 M41 逐字** + 信息行 `title` = M42 详注（三与门构成说明，悬停可见）；不隐藏开关（隐藏 = 功能永不可发现，定夺④） |
| **生成中** | 回合进行（generating） | 开关**已处于关态**（发送即复位，§2.3——不存在「生成中 + 开关开」的稳定态）；hint 右 = 存量「AI 回复生成中，发送暂不可用…」逐字零回退；开关可切换（只预置下一次发送；发送钮已呈停止态，REQ-010 零回退）；开关可用性不因 generating 变化 |

### 2.3 发送后复位时序（定夺③推荐：发送即复位）

```
① 开启开关        标签转 primary + hint 右 = M40 模式提示
② 输入开放问题    （输入行零变化）
③ 点发送 / Enter   请求体携带 mode:'research'（§2.4）
                   ⇩ 同一动作内：开关复位为关 + 标签回 --c-text-2 + hint 右回存量文案
④ 回合进行        开关保持关态不受回合影响；回合结束后下一次发送为普通回合（除非再开启）
```

- **复位 = `submit()` 内本地动作，不依赖回合结果**：HTTP 层失败（网络错误/4xx/5xx）时开关也已复位——保守方向回普通模式（低成本模式），误发损失最小化；这是「防高成本模式误连发」（REQ-047 定夺⑦附属）的落形。
- **开关状态不持久化**：不写 localStorage、不写会话档、不随会话切换携带（回合瞬时属性，REQ-047「mode 不写入会话档」的 UI 面对等口径）。
- **可用性翻转处置**：开关开启态下重取 quota 得 `research_available=false` → **开关强制复位 + 禁用**（前端预防）；若翻转未被前端感知（远端 admin 改动滞后），兜底 = 发送时后端 422 research_unavailable（§5/§6.3）。

### 2.4 请求体与复位数（数据面，vitest 断言面 = REQ-047 验收 1）

```
开启态发送：POST /api/chat/turn { session_id, message, mode:'research', [system_prompt?] }
关闭态发送：POST /api/chat/turn { session_id, message, [system_prompt?] }   ← 现状形状字节级不变（iter-13#42 复跑）
复位时点：  submit() emit('send') 后同步置 research=false（组件本地 ref，零服务端交互）
```

- `client.ts runChatTurn` 加法可选参数 `mode?: 'research'`——缺省不传（现状零变化，CHG-012 定夺⑦）；发送后复位由 ComposerBox 承载（App.vue send 回调零改动感知）。

### 3.3 布局叙事（一条 research 回合消息全貌）

```
[计划文本段]                      ← step1 流式（子问题 1. 2. 3. 分点可见）
[search 卡 ①折叠·完成 2380ms]
[引用来源卡 · 5 条]               ← tool.result(sources) 到达即现
```

- blocks 顺序 = 事件顺序（零重排规则，design-iter-13 §2 铁律）——计划与首轮检索合并在 step1 是 ReAct 自然行为（T0 §1 实证），文本段与工具卡交错全由事件序承载。

### 3.4 消息流模式徽标边界（有意不做）

消息流内（用户/AI 消息、卡片、pill）**零新增模式标识**：mode 不写入会话档（REQ-047），live 会话打「深度研究」徽标则历史重渲染（刷新/切端）不可重现——live/历史呈现不一致有意避免。模式的用户可见性收敛于输入区开关簇（发送前）与回合内容本身（计划/多卡/报告形态自释，发送后）。

## 4. 到顶标注态（REQ-046 异常分支步数/时长到顶 + REQ-047 验收 4）

沿 **maxSteps pill 体例**（design-iter-13 §3.4 / MessageBubble `.pill.max-steps`）：warning 族 = `--c-warning-l` 底 + `--c-warning` 字、12px、`--r-full`、padding 2px 10px、margin-top 6px；位置 = 消息末尾（`status !== 'generating'` 时呈现）；**零新形态——time_limit 沿体例出新文案**。

|---|---|---|
| `max_steps`（步数到顶，max_research_steps=16） | 「已到单回合步数上限」——**存量逐字零回退**（iter-13#29；research 回合同文案同形态，护栏数值差异不进文案） | 已生成计划/检索步骤/部分报告保留并落库 |

- **一回合一 pill**：reason 互斥，步数/时长到顶不并出（终态唯一）。
- 导出/复制不含 pill（过程标注不入正文导出——iter-13#45 同口径）。

## 6. research_available 判定源口径（随稿定案——T2/T3 实现依据；开关禁用态数据面）

### 6.1 API（GET /api/quota 加法字段）

```
GET /api/quota
→ 200 {
  "mode": "unified" | "self",          ← 既有四字段零变化（proxy.py read_quota L387-403 现状）
  "daily_limit": 30,
  "used_today": 3,
  "reset_at": "明日 00:00",
  "research_available": true           ← 新增（加法字段，bool）
}
```

- **判定 = 三与门**：（当前生效档案 `tools_enabled` 或统一 key）∧ admin `search_enabled` ∧ `search_key` 已配置——**与 search 工具下发门同源一处读两用**（proxy.py L218-222 现状挂点，CHG-012 内容 3.1；不新增独立判定路径，定夺⑧）。
- 加法扩展策略：既有消费方（KeyModeCard「每日 — 次」）忽略新字段零感知；老前端读新后端零影响。
- **前端缺省保守**：`research_available !== true` → 禁用态（字段缺失/异常一律不开放——不确定即禁用，铁律 5 精神）。

### 6.2 前端消费规则（定死，走查条 27/28 断言面）

| 场景 | 前端动作 |
|---|---|
| 应用启动（登录后） | 拉取 GET /api/quota → 定开关可用性 |
| 设置弹窗关闭后 | 重取（档案「支持工具」/密钥模式/档案切换可能改变三与门第一项） |
| 发送遇 422 research_unavailable | REQ-007 气泡 + 重取 quota 刷新禁用态 + 开关复位（§5） |
| 回合正常结束 | **不重取**（可用性非回合产物，避免每回合多余请求） |
| 生成中 | 开关可用性不因 generating 变化（开关可切换预置下一回合） |

### 6.3 滞后口径（快照非订阅）

判定源为**拉取时点快照**，非订阅推送——远端 admin 改动（关闭搜索/密钥失效）在下一刷新点（启动/关设置弹窗/422 后）前不被感知。**兜底 = 发送时后端受理即拒**（422 research_unavailable，零上游调用、零事件流，REQ-046 验收 5）。两级防线（前端禁用预防 + 后端受理拒绝）**单一权威 = 后端三与门**（前端禁用态仅为体验优化，非安全边界）。
