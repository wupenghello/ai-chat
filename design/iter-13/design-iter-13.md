## 2. blocks 展示层与 v1/v2 同流（REQ-032 / REQ-006 改写口径）

类型定义 = CHG-007 内容 4.2（text / tool_call / tool_result 三段，前后端共享语义），本稿不重复抄录，只登记展示规则：

| 规则 | 口径 |
|---|---|
| 读时归一化 | v1（content: string）⇒ `[{type:'text',text:content}]`，进同一渲染管线——**逐字零回退**（含 branches/编辑态/版本切换，REQ-032 验收 1） |
| 消息级判定 | v1/v2 按 content 类型（string vs array）判定，与会话档顶层 `schema: 2` 独立——branches 内 v1/v2 混合各自归一化 |
| 顺序渲染 | 文本段与工具卡按 blocks 顺序呈现，不重排、不合并跨工具卡文本段；段间 8px、消息间 20px 沿用 |
| 写侧 | 用户消息恒 string（现状）；assistant 消息 v2 起用 blocks（至少一段）；回合事件流组装规则见 §4 |
| 文本段管线 | 仅 text 段进 markdown-it + DOMPurify（REQ-011 改写）；工具参数/结果不进 Markdown 管线 |
| 适配面 | 复制 = 文本段空行拼接（工具内容不入）；导出 = 文本段照旧 + 工具段一行 `> [工具 name · 状态]`（状态词：完成/失败/超时/已中断；v1 会话导出逐字不变）；搜索 = 文本段拼接索引（工具内容不入，REQ-016 定案）；编辑重建 = 删后消息 + 发起服务端回合（v2 响应） |

## 3. 工具步骤卡 UI 规格（定夺⑤=4.8-5 载体）

AI 消息流内次级面板：`--c-subtle-bg`（#FAFBFC/#24272E）+ 1px `--c-border` + `--r-md`；头部行常显可点击（button，aria-expanded，Enter/Space，:focus-visible 焦点环）。

### 3.1 状态徽章四态 + 派生中断态（20px 胶囊 · 12px/500）

| 状态 | 来源 | 配色（浅/暗） | 语义 |
|---|---|---|---|
| 运行中 | tool.call | `--c-primary-l`/`--c-primary`（#F0F4FF·#3370FF / #1D2740·#5C8DFF）+ 11px spinner | 执行中（单工具超时约束）；结果占位「（等待结果…）」 |
| 完成 | tool.result(ok) | `--c-surface` 底 + `--c-success` 字 + border + ✓（#1A9E5C / #4CC38A） | 结果挂载（网关截断后文本原样渲染）+ 耗时 |
| 失败 | tool.result(error) | `--c-danger-l`/`--c-danger`（#FDECEA·#D93025 / #361B18·#FF8073）+ ✕ | 错误回填模型，**回合继续**降级直答 |
| 超时 | tool.result(timeout) | `--c-warning-l`/`--c-warning`（#FFF7E8·#B45309 / #38290F·#EDA23B）+ 时钟 | 时效性失败与确定性失败分色；回合继续 |
| 已中断（派生） | tool_call 无匹配 tool_result（aborted/中断/停止后落库） | `--c-hover-bg`/`--c-text-2`（中性「—」icon） | **运行中徽章不得冻结留存历史**；结果占位「（回合中断，未获得结果）」 |

超时用 warning 不用 danger 的理由：error = 确定性拒绝（重试同样失败），timeout = 时效性失败（重试可能成功）——沿全站三族语义色既有语言，与「生成中断」（warning）同族。

### 3.2 折叠规则 R1~R3（默认态）

- **R1**：tool.call 到达 → 卡创建即**展开**（过程可见 = A1 北极星）。
- **R2**：终态到达 → 用户**未手动操作过**该卡则**自动折叠**（头部行承载终态徽章 + 耗时）；操作过则保持用户态。
- **R3**：历史消息（读库渲染）**恒折叠**。
- 头部行：工具 icon 14px `--c-text-3` + 名称 13px/500（ellipsis）+ 参数摘要 mono 12px verbatim（ellipsis）+ 耗时 12px tabular `412ms`（仅终态）+ 徽章 + chevron（.15s 旋转）。

### 3.3 展开区（参数块 + 结果卡）

- 参数块：label「参数」+ surface 内面板 mono 12px，arguments JSON **原样**（零转换）；超长横向滚动。
- 结果块：label「结果」+ surface 内面板 13px/1.6 pre-wrap；**左缘 3px 语义色条**（ok/error/timeout）；**max-height 200px** 内滚（细滚动条）。
- 占位三串：「（等待结果…）」/「（无返回内容）」（空 result）/「（回合中断，未获得结果）」。
- 截断标注：后端在 result 尾部追加（文案 T1 定，CHG-007 4.5），前端**原样渲染**。

### 3.4 回合级标注与逐字文案登记（v1.4.10 B 断言面）

| 文案（逐字） | 触发 | 形态 |
|---|---|---|
| 已到单回合步数上限 | turn.end(max_steps)（文案随本稿定死，REQ-030） | 消息末尾 warning pill；已生成内容保留落库 |
| 生成中断 / 已停止生成 / 正在生成… | 中断 / 停止 / 回合中 | **存量逐字零回退**（iter-1 基线） |
| 徽章五串：运行中/完成/失败/超时/已中断 | — | §3.1 |
| 占位三串（见 3.3） | — | §3.3 |
| 块标签：参数/结果；耗时 `412ms` | — | §3.3 |
| 导出标记行：`> [工具 demo_weather · 完成]` | REQ-013 改写，格式随本稿定死 | §2 适配面 |

后端拥有文案（前端原样渲染）：截断标注（T1 定）、tool.result 错误原因、409 `session_schema_conflict` detail.message。A1 无固定「降级直答」标注文案（模型自述）；A2 搜索降级文案随 design-iter-14。

## 4. SSE 协议 v2 前端契约（REQ-030 事件面）与回合边界（REQ-033）

承载 = 独立端点 `POST /api/chat/turn`（定夺⑦推荐定案）；事件负载字段 = CHG-007 4.1 原文。

### 4.1 九类事件消费规则

| 事件 | 前端处理 |
|---|---|
| turn.start | **建回合态**：创建 assistant 消息（streaming）+「正在生成…」hint + 光标；发送钮呈停止态 |
| text.delta | 追加当前文本段；工具事件后首帧**开新文本段**（blocks 顺序 = 事件顺序） |
| tool.call | 按 tool_call_id 开卡（运行中徽章、展开 R1）；arguments 原样入摘要与参数块 |
| tool.result | 按 tool_call_id 匹配更新：终态徽章 + 结果（原样）+ 耗时 + R2 折叠 |
| turn.step | **不渲染**（步数记账；护栏仅以回合级终态标注呈现） |
| usage | **不渲染**（落 usage_daily 由服务端完成，REQ-034） |
| turn.end | **定型**：移除 hint；reason 映射 done→status=done / max_steps→上限 pill / aborted→停止·中断 pill / error→错误分支标注；定型后触发**会话 PUT（整档，顶层 `"schema": 2`）** |
| error | **完全复用 REQ-007 / design-iter-7 §3.1 十场景错误气泡**（可重试者重试 = 新回合）；已生成文本与工具步骤保留 |
| upstream_interrupted | 内容保留 +「生成中断」pill（存量口径）；运行中卡转「已中断」 |
| **未知 type** | **静默跳过**：不渲染、不抛错、不中断回合（parseSse 前向兼容沿用，为 B/C/D 期留扩展位） |

回合态规则汇总：turn.start 建立 → 期间可停止（aborted）→ turn.end 定型 → PUT。断连取消由服务端检测并取消上游与工具执行（前端无孤儿态；已落库内容保留，REQ-006 恢复口径衔接）。

### 4.2 请求体边界（组装迁服务端）

```
POST /api/chat/turn
{ "session_id": "s_ab12", "message": "北京今天天气怎么样？" }   ← 仅两字段，无历史数组
→ 200 text/event-stream（九类事件）
```

> **基线后补注（2026-08-17，T1 实现时登记，见 plans/iter-13-verify.md §4.1）**：请求体含可选第三字段 `system_prompt`（REQ-008 的全局系统提示词存前端 localStorage，服务端组装需随回合上传）；「无历史数组」口径不变。

- 前端不再组装与上传历史（buildContext 读路径退役；系统提示词 + 最近 20 轮由服务端组装器执行，规则照搬）。发送/编辑重建/重新生成**统一走回合端点**；编辑重建 = 先按 REQ-015 删后消息并保存会话，再发起回合。
- **旧透传端点 `POST /api/chat` 零改动保留**（老客户端窗口期；1 请求 = 1 回合计、配额同源）；下线时点 B1 评估——T0/T1/T2 不得擅自移除。
- 配额 429 回合受理即拦（零上游调用、零工具卡；提示沿现状口径）。

### 4.3 schema: 2 写侧守卫的前端配合（CHG-007 4.3）

turn.end 定型 → PUT 整档（顶层 `schema: 2`，新客户端恒带；REQ-032 验收 3 vitest 断言）；GET 原样 JSON 读时归一化、标记透传不剥离；新客户端遇 409（理论不触发）→ REQ-007 体系提示 + detail.message 原样 + 引导刷新，不自动重试。

## 5. 暗色主题同步口径

- 机制不变：根节点 `[data-theme="dark"]` 覆盖令牌，组件零感知（tokens v1.3）；工具卡全部 `var()` 引用（含 spinner currentColor、焦点环、滚动条）。
- 关键组合（暗色，tokens v1.3 计算值）：卡底 #24272E 上徽章字——运行中 #5C8DFF 5.2:1 族、完成 #4CC38A 7.4:1 族、失败 #FF8073 6.5:1 族、超时 #EDA23B 6.6:1 族、中性 #A2A9B6 6.9:1 族（12px/500 非正文口径）；正文组合沿 v1.3 既有结论（≥4.5:1）。
- 走查方法：§5.1/5.2 锁定双帧（五态卡 + 消息流）并置，暗帧内任何肉眼发白块 = 漏改裸色值；**全清单条目亮暗各过一遍**（双主题承载口径，v1.4.10 B 条）。

### 定夺④联动定案建议（须随④一并拍板）
