## 1. 范围与不做

- **做**：设置弹窗第六分区「AI 的记忆」全规格（七态：列表 / 编辑 / 删除确认 / 整体停用 / 注入预览 / 空态 / 加载失败）；样件文案逐字登记表 M1~M37（v1.4.10 B 唯一来源）；API 口径章节定案（四端点形状 + 归属隔离 404 + 422 校验语义 + PUT 来源归零语义 + 前端消费规则）；REQ-028 既有五分区 + REQ-007 直达零回退映射（逐条对 iter-11#37~45）；走查清单 34 条（三断言面 + 双主题）。
- **不做**（登记防膨胀）：admin 记忆抽取卡（CHG-011 定夺⑩ REQ-044 不立项，admin 可见性入暂缓池）；单条停用开关（定夺⑥定案：删除/编辑已覆盖该诉求，单条停用 UI 面翻倍价值有限）；手动新增记忆入口（CHG-011 内容 3.7 API 框架无 POST 端点——记忆唯一来源 = 对话自动抽取，手动新增如未来需要走 CHG）；回合内注入提示（定夺⑨：SSE 事件流零变化，注入可见由页内预览承载）；主对话面任何触达（消息流/输入区/顶区零新增元素——记忆注入为服务端组装行为，前端回合数据面零改动，同 B2 先例）；design/proto 不同步（iter-1 核心闭环原型定位，记忆对其不可见，CHG-011 影响评估口径）；移动端（CHG-007 让位定序）。

## 2. 分区页形态规格（七态）

### 2.1 位置与布局（定夺①）

| 项 | 口径（随基线定案） |
|---|---|
| 载体 | SettingsForm `TABS` 数组**加法一项**——`{ key: 'memory', label: 'AI 的记忆' }`，插在「对话设置」之后、「账号」之前（CHG-011/REQ-028 改写定序）；组件机制零改动（showPane/onNavKey 取模循环随 TABS.length 5→6 自然涵盖） |
| 分区内序列（自上而下） | ① 标题 + 说明句 → ② 停用开关行 → ③ 记忆列表 → ④ 注入预览（折叠置底） |
| 位置理由 | 开关 = 分区级总闸置顶（其态决定下方列表/预览的呈现分支）；列表 = 主任务居中；预览置底折叠——30 条满载预览约 4.8k 字符，常显把列表挤出首屏；备选「预览置顶常显」未采纳（可见性不因折叠受损，一次点击展开） |
| 标题与说明 | 标题 M2「AI 的记忆」（section-label 既有形态 14px/600 `--c-text-1`）；说明句 M3「记忆由对话自动沉淀，AI 在回复时参考；你的修改自下一回合起生效。」（12px/1.7 `--c-text-3`，mode-note 家族）——**「下一回合生效」时效口径常驻自释** |

### 2.4 删除确认（定夺③：ConfirmModal 现状组件照搬）

360px alertdialog：标题 M19「删除这条记忆？」（17px）+ 正文 M20「删除后 AI 将不再参考这条记忆，此操作不可撤销。」（14px `--c-text-2`）+ 32px 钮「取消 / 删除」（M21，danger-solid 实底白字）；Esc / 遮罩点击 = 取消（组件既有行为）；z-150 Teleport 形态零改动（iter-11#43 层叠口径）。确认 → DELETE → 成功 toast M31 + 重取 GET；失败 toast M35 + 重取 GET。

### 2.5 整体停用（定夺④：灰显 + 操作冻结）

| 项 | 规格 |
|---|---|
| 开关行 | tools-field 家族行容器（padding 12px + 1px border + r-md + `--c-subtle-bg` 底）；标题 M4「AI 参考记忆」13px/500 + 说明 12px `--c-text-3`；开关 = ToggleSwitch 组件零改动（components.md v1.3）+ aria-label M5 |
| 停用态呈现 | 开关置关 → 通知条 M6「记忆已停用：AI 不再参考任何记忆，也不再进行新的沉淀。已有记忆保留，重新启用即恢复。」（`--c-warning-l` 底 + `--c-warning` 字，注意语义非错误）+ **列表灰显 opacity .45 + 条目编辑/删除钮 disabled** + 预览块显停用句 M24 |
| 停用语义（REQ-042） | 注入跳过且后台扫描跳过（不新抽取）；存量记忆保留，重新启用即恢复注入；停用零回退：组装与基线 v7 逐字段等价（pytest 面） |

### 2.6 注入预览（定夺⑤：折叠 + 代码块样式；定夺⑨逐字同源）

| 项 | 规格 |
|---|---|
| 形态 | 折叠块置底：**默认折叠**；头行 button 语义（aria-expanded + chevron .15s 旋转）= M22「注入内容预览」13px/500 + 说明 M23「所见即所注：以下文本在每个回合组装时逐字注入对话开头」12px `--c-text-3` |
| 展开区 | 代码块族令牌：`--c-code-bg` 底 + `--c-code-text` 字 + mono 12px/1.7 + pre-wrap + max-height 220px 内滚（细滚动条 `--c-scrollbar`）——**深底代码语义自释「这是逐字注入物，不是界面文案」**，两主题均深底（浅 #2B303A / 暗 #191B20） |
| 内容来源（铁律级纪律） | 恒为 GET /api/memory `injection_preview` 字段**逐字**，**前端零本地拼装**——单一链路保证「看到的就是注入的」；服务端预览取值与回合组装共用同一拼装函数（组装时点逐字同源，CHG-011 内容 3.7） |

toast 形态：成功态 = ✓ 前缀调用方拼入 + success 变体绿字（沿 SettingsForm 改密/注销成功先例）；默认白字态 3s 自动消失、顶部居中（AppToast 现状形态零改动）。

## 4. API 口径（随稿定案——T2/T3 实现依据；体例沿 design-iter-14 §6 / design-iter-16 §5）

硬门槛：既有全部端点形状零变化（turn/sessions/profiles/admin/settings/telemetry 逐字节不动，仅加法四个 memory 端点）。框架口径 = CHG-011 内容 3.7；detail 对象形状沿 `sessions.py` 409 `session_schema_conflict` 先例（`{code, message}`，client.ts 既有消费链路直接支持）。鉴权 = 会话 token（CurrentUser 同款依赖）；user_id = token 身份，跨用户操作一律 404（归属隔离沿复合主键哲学，REQ-043 验收 5）。

### 4.1 GET /api/memory（列表 + 停用状态 + 注入预览，一次取全）

```
→ 200 {
  "entries": [
    { "id": 1,
      "content": "要求 AI 用简洁的中文回复，避免冗长解释，不使用表情符号。",
      "source_session_id": "s_c7d2",               ← 抽取来源会话；用户手工编辑后归 null（§4.2）
      "source_session_title": "迭代计划流程设计",    ← 组装时读会话档 title；会话已删 → null（UI 落 M11 分支）
      "model": "deepseek-chat",                    ← 抽取模型（机器记录；手工编辑后归 null）
      "created_at": "2026-08-19 21:04:11",
      "updated_at": "2026-08-19 21:04:11" }, …
  ],
  "memory_enabled": true,
  "injection_preview": "<user_memory>\n以下是关于用户的长期记忆（自动从历史对话抽取），回复时作为用户背景参考：\n1. …\n</user_memory>" | null
}
```

- **entries 数组顺序 = 注入组装顺序 = 预览编号顺序**（一一对应；前端不排序不改序）。
- **injection_preview = 回合组装同一拼装函数的组装时点逐字取值**（「看到的就是注入的」，定夺⑨）；memory_enabled=0 或 entries 空 → `null`（没有注入发生，不呈现注入物——铁律 5）。
- 上限口径：entries ≤ 30 条、单条 ≤ 150 字（T0 收紧定案，verify §3；本端点只读，截断在抽取侧）。

### 4.2 PUT /api/memory/{id}（条目编辑）

```
{ "content": "…" }                                ← body 仅此一字段
→ 200 { "id": 1, "content": "…", "source_session_id": null, "source_session_title": null,
        "model": null, "updated_at": "…" }
        手工编辑 = 条目转用户所有：来源与模型归零（UI 元信息落 M12 分支）
→ 404 { "detail": { "code": "memory_not_found", "message": "记忆不存在" } }
        不存在或属他人（归属隔离一律 404，不泄露归属）
→ 422 { "detail": { "code": "memory_content_invalid", "message": "记忆内容不能为空，且不超过 150 字" } }
        trim 为空 / 超 150 字（前端 maxlength 双保险，服务端为唯一权威校验）
```

### 4.3 DELETE /api/memory/{id}（条目删除）

```
→ 200 { "detail": "deleted" }                     ← 形状沿 sessions.py DELETE 先例
→ 404 memory_not_found（同上归属隔离）
```

### 4.4 PUT /api/memory/settings（整体停用开关）

```
{ "memory_enabled": false }
→ 200 { "memory_enabled": false }
→ 422 非法 body（缺字段 / 非布尔）
```

### 4.5 竞态与生效时效（REQ-043 异常分支定案）

- **回合进行中编辑/删除/停用：允许，无 409 竞态面**——记忆非会话组装实体组成部分，注入在回合受理组装时点读库；前端零预判 generating 状态（单一链路，同 iter-16 定夺④哲学）。
- **生效时效**：编辑/删除/停用均自下一回合生效（组装读库时点天然涵盖，REQ-042 主流程 4）；用户可见面 = toast 成功文案统一带「下一回合生效」标注（M30/M31/M33）。
- **无 POST 端点（有意边界）**：记忆唯一来源 = 对话自动抽取；「手工编辑」仅指对既有抽取条目的改写（PUT 后来源归零）。手动新增入口如未来需要走 CHG。

### 4.6 前端消费规则（定死，走查条 12/18/22/27 断言面）

| 场景 | 前端动作 |
|---|---|
| 打开分区（pane 切入） | GET /api/memory → 成功渲染三态之一；失败 → 加载失败态（M28+M29） |
| 重试 | 重发 GET（可重入，沿 retryBoot 先例）→ 成功恢复列表态；失败停留失败态（不重复 toast） |
| PUT 条目成功 / 失败 | 成功 toast M30 → **重取 GET 整分区刷新**（前端零本地拼装预览）；422/404/其他 → toast M34 + 重取 GET 恢复服务端真态，编辑态关闭 |
| DELETE 成功 / 失败 | 成功 toast M31 + 重取 GET；失败 toast M35 + 重取 GET |
| PUT settings 成功 / 失败 | 成功 toast M32/M33 + 重取 GET（停用态以服务端 memory_enabled 为准）；失败 toast M36 + 重取 GET 回滚开关位（零乐观更新） |
| 请求在途 | 开关 disabled 防重复；编辑保存钮禁用；无全局 loading 遮罩（分区级轻操作） |
