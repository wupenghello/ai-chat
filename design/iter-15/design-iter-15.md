## 3. 四区规格摘要（全文见 index.html §1.2~1.4）

- **卡 A 每日成本估算**：标题 + 副题「仅统一 key 模式计成本；自填模式 tokens 不计成本」（口径明示于卡面）；大数值 = 今日成本估算（20px/600 tabular，¥ + 4 位小数）；分项三列（输入/输出/缓存命中：tokens + 分项小计）；**单价行 admin 只读**（「单价（只读）」+ 三单价值 + 「单价由 backend/.env 三变量 AI_CHAT_PRICE_* 注入，admin 只读」——全稿无编辑入口）；**自填行**「自填模式（用户自带密钥）：tokens X · 不计成本」+「不计成本」徽标（定夺⑥逐字）。
- **卡 B 缓存命中率**：说明常驻「命中率 = Σ缓存命中 tokens ÷（Σ命中 + Σ未命中）· 仅统计上游返回缓存字段的调用」；大数值 = 窗口合计命中率（NN.N%）；按日四列表（日期/命中/未命中/命中率）；缺失日 = tokens「—」+「缺失」琥珀徽标（**永不显 0**；合法 0 值如实显 0——T0 取证语义）。
- **卡 C 工具用量**：说明常驻「按工具名 × 状态聚合；search 为当前唯一生产工具（本视图即搜索用量面板）」（暂缓池主题包⑤承载声明）；四列表（工具名/状态/次数/平均耗时）；状态徽标四态（成功/失败/超时/已取消，色组合沿徽章家族）；空态「窗口内无工具调用记录」。
- **卡 D 按日成本明细**：六列表（日期/输入 tokens/输出 tokens/缓存命中 tokens/成本估算/自填 tokens（不计成本））；缺失时段琥珀行「部分时段无统计数据：仅显示已有数据（不估算补齐）」（iter-12 口径逐字沿用）；无数据日不造空行。
- **文案逐字**：全部用户可见文案 28 条登记于 index.html §2（T1~T28），为走查逐字断言唯一来源（v1.4.10 B）。

## 4. 两异常形态 + 三个辅助态（index.html §3.1 状态矩阵全文）

| 态 | 触发 | 用户所见 |
|---|---|---|
| **缺失时段** | 窗口内部分自然日无遥测行 | 卡 D 琥珀行标注；表格仅列有数据日；不补零行不估算（铁律 5，REQ-025 既有口径） |
| **单价未配置** | `price.configured=false` | 卡 A：成本位「—」、tokens 如实显示、warning 提示（含三变量名与重启指引）；卡 D 成本列「—」；卡 B/C 不受影响——**不出现任何成本数字** |
| 缓存字段全缺失 | 窗口内全部 llm 行缓存列 NULL（如仅 GLM 类自填流量） | 卡 B 合计位「缺失」徽标（不显 0%/NaN）；按日行同缺失口径 |
| 空窗口 | 窗口零遥测行 | 面板整体空盒「窗口内无遥测数据——新部署或尚无对话的日子属正常现象」（非错误态） |
| 加载/失败 | 请求在途 / 网络·5xx | spinner「正在加载遥测数据…」/ danger banner「遥测数据加载失败」+ 重试（保留时间窗选择） |

**0 与缺失的区分纪律（铁律 5 走查要点）**：0 = 机器采集真值如实显示；缺失 = 上游未返回字段（NULL → 徽标/「—」）或该日无行（整行不列 + 琥珀行）——二者视觉语言不同（走查条 27/37）。

## 5. API 口径（随稿定案——T3 实现依据；全文与响应示例见 index.html §4）

硬门槛：**既有六端点（users/ban/unban/quota/usage/overview）+ PUT /api/admin/settings 形状零变化**，既有 admin pytest 用例零改动复跑全绿（REQ-038 验收 1）。遥测为**新增一个只读聚合端点**（加法扩展，不触既有端点）。

```
GET /api/admin/telemetry?days=7          （days 整数 1~90 默认 7；越界/非整数 → 422）
门禁：get_admin_user（与既有六端点同一依赖）；非 admin → 403，响应体零遥测字段
→ 200 {
  "window": { "days", "date_from", "date_to" },        ← date_to = 服务器本地今日（quota.today 口径，与 usage_daily.day/telemetry.day 同源）
  "price":  { "configured", "input_per_mtok", "output_per_mtok", "cache_hit_per_mtok" },   ← 元/1M tokens；未配置 → configured=false
  "today_cost": { day, tokens_prompt, tokens_completion, cache_hit_tokens,
                  cost_input, cost_output, cost_cache_hit, cost_total,    ← 单价未配置 → cost_* 全 null（tokens 如实）
                  self_tokens_total },
  "daily": [ { day, tokens_prompt, tokens_completion,
              cache_hit_tokens, cache_miss_tokens, cache_rate,            ← 缓存列 NULL → null；cache_rate null = 该日缺失
              cost_total, self_tokens_total }, … ],      ← 仅列有数据日（缺失时段由前端以窗口比对判定）
  "tools": [ { tool_name, status, count, avg_duration_ms }, … ],          ← GROUP BY tool_name,status；排序 tool_name ASC, status ASC
  "retention_days": 90
}
```

- **聚合公式（CHG-009 4.3 定案口径）**：`cost_input = Σtokens_prompt × input_per_mtok ÷ 1e6`（仅 mode='unified' llm 行），output/cache_hit 同法；`cost_total` = 三项和；后端保留 6 位小数、响应数值型；`cache_rate = Σhit ÷ (Σhit+Σmiss)`（日级仅计带字段行——**部分缺失口径**：混合日不弹提示、整天无带字段行显缺失）；工具 = 行数与耗时均值。全部机器聚合，无手工修正入口（铁律 5）。
- **单价变量**：`AI_CHAT_PRICE_INPUT / AI_CHAT_PRICE_OUTPUT / AI_CHAT_PRICE_CACHE_HIT`（元/1M tokens，非负小数；任一缺失/非法 → configured=false）；与统一 key 三变量、人设变量同法 `.env` 注入，`.env.example` 占位随 T2 补；admin 只读（全仓库无写价端点与 UI，改价 = 改 .env + 重启）；不入日志。
- **与 T0 取证一致性声明**：统一 key（DeepSeek）缓存字段恒返回 → 命中率恒可算、未命中为 0 如实；GLM 类自填 NULL → 显缺失——本口径的 NULL/缺失语义即 T0 §2.4/§3.2 结论的呈现层落地，无臆断字段。
