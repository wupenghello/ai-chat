## 部署步骤

1. 前置：机器装 Docker；`cp backend/.env.example backend/.env` 并填统一 key 三变量（可留空，对话返回引导文案）
2. `docker compose up --build -d`（frontend :8080 + backend :8000 + 数据卷 ./data）
3. 验证：`curl localhost:8080/api/health`；浏览器开 `http://localhost:8080` 注册首个账号（自动成为管理员）
4. 冒烟：注册→对话→改密→注销全链路

## 回滚方案

- **服务回退**：`docker compose down` 停止前后端；数据在 `./data/ai-chat.db`（增量迁移 user_version，卸载不清数据）。
- **代码回退**：`git checkout v0.4.0`（上一版静态站点）重新部署 gh-pages；v0.5.0 无线上部署，回滚即「本地停服 + 代码回 tag」，预计 <5 分钟。
- 冒烟失败：立即 `docker compose down`，登记缺陷，发布记录标注「发布失败及原因」，进入下个迭代修复。
