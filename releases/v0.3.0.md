## 本版包含

自 v0.2.0 以来，iter-4（T0~T3 + CHG-003 快速通道）交付：

| 需求/缺陷 | 说明 |
|------|------|
| REQ-015 | 消息编辑与重新生成（修改历史消息 → 删后文重建；生成中编辑中断；generation 纪元防竞态） |
| REQ-016 | 会话搜索（标题/正文命中、标题优先排序、关键词主色高亮、正文命中片段、无匹配空态） |
| REQ-019 | 版本切换（编辑后新旧分支 ‹ 1/2 › 箭头切换，branches 深拷贝归档随会话持久化） |
| DEF-011 + CHG-003 | 输入框对齐 DeepSeek 形态（按钮与 textarea 同排顶对齐）；消息下方操作栏（复制/修改 icon-only + hover + tooltip） |

质量证据：79/79 测试、走查 28/28（plans/iter-4-verify.md）、QA 审计 5 NCR 全整改（retros/qa-audit-iter-4.md）、生产构建通过（vue-tsc + vite build）。
