## 部署步骤（VPS 全新机，Ubuntu 22.04/24.04；完整命令手册随本稿呈报）

1. 基线：系统更新、时区 Asia/Shanghai（配额按自然日重置）、ufw 放行 22/80/443、安装 Docker（get.docker.com）
2. 代码：`git clone https://github.com/wupenghello/ai-chat.git /opt/ai-chat`（公开仓库）
3. 配置：`backend/.env`（统一 key 三变量 + `AI_CHAT_COOKIE_SECURE=1`，其余默认）；compose 端口改绑 `127.0.0.1`（8080/8000 不外露，宿主 nginx 独占入口）；`dist/` 本地构建后上传（不入 git）
4. TLS：宿主 nginx 站点（443 → 127.0.0.1:8080，SSE 口径：proxy_buffering off / read_timeout 300s / HTTP 1.1 / Connection ""）+ `certbot --nginx` 签发与强制跳转
5. 起服务：`docker compose up --build -d`，backend + frontend 双 healthy
6. 冒烟按上列验证点逐项执行并记录输出

## 回滚方案

- **服务回退**：`docker compose down`（分钟级下线；数据保留 `./data/ai-chat.db`，卸载不清数据）
- **版本回退**：同形态内 `git checkout <上一提交>` + `docker compose up --build -d`；v0.4.0 为静态站旧形态，不作为线上回退目标
- 冒烟失败：立即 `docker compose down`，登记缺陷，发布记录标注「发布失败及原因」，进入下个迭代修复
