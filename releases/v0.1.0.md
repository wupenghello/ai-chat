## 回滚方案

- **怎么退**：`git push origin --delete gh-pages`（Pages 即 404）；或 `gh api -X DELETE repos/wupenghello/ai-chat/pages` 关闭站点
- **退到哪**：回到"仅本地 dev 可用"状态（发布前状态）；本地与 tag `v0.1.0` 代码不受影响
- **预计耗时**：< 2 分钟；线上无服务端数据需要迁移（用户数据全在本机浏览器 IndexedDB）
