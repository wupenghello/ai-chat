## 部署步骤

1. `npm run build:pages`（vite build，`--base=/ai-chat/` 适配 GitHub Pages 子路径）
2. 将 `dist/` 推送到 ai-chat 仓库的 `gh-pages` 分支
3. 用 `gh` 开启仓库的 GitHub Pages（来源 gh-pages 分支）
4. 访问 `https://wupenghello.github.io/ai-chat/` 冒烟验证
5. 已确认 DeepSeek API 允许该来源跨域直连（CORS 预检实测通过）

## 回滚方案

- **怎么退**：`gh api` 把 Pages 来源切回空，或直接删除 `gh-pages` 分支（`git push origin --delete gh-pages`）；本地与 tag `v0.1.0` 的代码不受影响
- **退到哪**：回到"仅本地 dev 可用"状态（发布前的状态）
- **预计耗时**：< 2 分钟；线上无数据需要迁移（用户数据全在本机浏览器 IndexedDB，不依赖服务端）
