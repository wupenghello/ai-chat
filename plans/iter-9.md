## 风险清单

| 风险 | 应对 |
|------|------|
| 注销不可逆（删除全部云端数据），误触或实现缺陷致数据丢失 | 密码二次确认强确认 + 级联删除在事务内 + pytest 覆盖「二次确认不匹配则数据不变」「删除后库中检索不到」 |
| 改密「其他设备 token 失效」遗漏，改密后旧 token 仍可访问 | pytest 覆盖验收原文「另一设备旧 token 返回 401」 |
| v0.5.0 发布形态由静态站点变前后端服务，Compose 首次引入前端产物服务（静态托管 + API 反代路径）可能出错 | `compose up` 全链 healthcheck 验收 + 自部署文档按实际跑通写 + release checklist 补部署验证项 |
