## 迭代目标

手机（≤768px/≤480px）上能完成「找会话 → 看消息 → 发消息 → 改设置」全闭环：侧栏抽屉化不再挤压正文、设置弹窗全屏化可用不溢出、2 处 hover 功能入口触屏可达；桌面（>768px）布局与行走为**逐像素零变化**（既有走查基线复跑零回退、vitest 378 存量全绿、pytest 347 复跑背书）。

### T1 design-iter-20 设计基线（M）

**工作项**：

1. **≤768px 抽屉形态**：侧栏 fixed overlay + 遮罩（`--c-mask` 既有值）、入口钮位置（顶栏或正文左上，形态定案）、开合动画、选会话/遮罩/Esc 关闭口径；>768px 现行双列/rail 形态以「桌面形态零变化」注记机制化表达（沿 CHG-014 设计资产承载口径：既有桌面原型不同步）。
2. **≤480px 全屏弹窗态**：SettingsForm 全屏化形态（inset 0、单滚动、关闭钮/Esc/返回路径）、左侧导航转横向滚动条或分段切换（定夺④范围内定案）、内嵌二级弹窗（改密/注销）同口径形态。
3. **≤480px 正文收窄**：正文列 padding 收窄、气泡 max-width ≤92%、composer-row padding 12px、发送钮 36→44px 或热区扩大（视觉尺寸定夺）、Enter hint 触控口径文案、信息行窄屏布局。
4. **触屏常显态样式**：会话「···」与消息操作栏 `hover: none` 常显形态；44px 命中区实现口径（视觉不变热区扩大 vs 视觉放大，定稿）；active 态兜底。
5. **走查四象限清单**：≤768px/≤480px × 明/暗双主题断言条目（几何断言面 v1.4.11 B + 行为断言面 v1.4.13 B 适用项）+ 桌面基线全量复跑清单（零变化断言）；REQ-026 rail 走查 16~18、REQ-028 弹窗、REQ-003/004/005/012/016 零回退组逐条映射既有走查编号。
6. **卫生项**：spec REQ-049/050/051「涉及页面」指针随基线零滞后回填（v1.4.10 A 防线）。

**判定依据**：CHG-014 内容 5 设计资产承载段明文「新增 design-iter-20 设计任务（定夺⑧前置）」+ 影响评估拆解「T1 设计 M（2：双断点双面设计基线 + 走查四象限清单）」。类比：iter-16 design-iter-16（2 触点 + API 口径 + 四态）定 M；本次 2 断点 × 2 面 + 触屏横切态 + 四象限清单，规模同档取 M。
